# YouWissKommKomm Korpus

Dieses Repository enthält die Beschreibung des Korpus *YouWissKommKomm*, eines Korpus, das aus Kommentaren zu wissenschaftlichen YouTube-Videos besteht. 
Zudem sind Links zu allen Videos enthalten, aus denen die Kommentare extrahiert wurden.

Siehe `YouWissKommKomm_corpus-doc.md` für weitere Informationen.
